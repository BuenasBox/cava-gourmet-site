# CAVA Luxury Audit Skill

This skill directs the agent to audit and optimize the CAVA Vinoteca website with a luxury hospitality lens.

## When to use
- Review `index.html` for production hardening.
- Audit performance, Core Web Vitals, technical SEO, accessibility, and GitHub Pages compatibility.
- Propose minimal, elegant code changes that preserve premium design.
- Support architecture-level decisions for entity SEO, brand moat, and international positioning of Nazareth Padilla.

## Workflow
1. Read the existing `index.html` and supporting deployment docs.
2. Identify quick wins and critical issues first.
3. Evaluate impact on:
   - Performance and Lighthouse
   - SEO metadata and schema
   - Accessibility WCAG and keyboard navigation
   - Mobile-first experience
   - GitHub Pages path/case-sensitivity risks
   - Brand moat and entity authority
4. Propose concrete fixes with a ready-to-use diff or code block.
5. Keep all changes lightweight and aligned with the brand tone.

## Constraints
- No generic or broad redesign proposals.
- Do not alter the site palette, typography, or narrative unless explicitly requested.
- Prefer `criterio experto`, `selección especializada`, `dirección enológica`, `acompañamiento en selección`.
- Avoid `curaduría`.
- Use vanilla HTML/CSS/JS only.

## Useful prompt examples
- "Use the CAVA Luxury Audit skill to improve the hero LCP and metadata in `index.html`."
- "Audit the current GitHub Pages deployment risks and propose fixes with exact code changes."
- "Review technical SEO, accessibility, and performance for CAVA Vinoteca and return prioritized concrete fixes."
- "Evaluate schema and social preview changes that strengthen Nazareth Padilla's authority and the Costa Rica luxury wine positioning."
